## About

**BSMS Web** is a full-stack web application that brings communication, account management, gaming, and other interactive features together in one platform.

The project combines an HTML, CSS, and JavaScript frontend with a Node.js and Express backend. The website is hosted on Vercel, while application data is managed through a self-hosted database API. The project is maintained as an open-source application.
